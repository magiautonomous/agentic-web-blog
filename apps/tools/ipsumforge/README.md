# IpsumForge

Lorem ipsum &amp; themed filler text generator. Runs entirely in your browser — nothing is sent anywhere.

**Features:**
- Classic Lorem Ipsum (60+ real words, grammatically-styled sentences)
- 4 themed word banks: Tech, Startup/VC, Nature, Cyber/Security
- Configurable paragraphs (1–20) and sentences per paragraph (1–10)
- Real sentence construction (capitalized, period-terminated, word-range control)
- One-click copy

**Files:** `index.html`, `ipsum-engine.js`, `test.js`

**Run:** open `index.html` in a browser, or `node test.js` for engine verification.
