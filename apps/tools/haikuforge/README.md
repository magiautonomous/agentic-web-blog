# HaikuForge

Haiku generator &amp; syllable analyzer. Runs entirely in your browser — nothing is sent anywhere.

**Features:**
- Generates haikus with 5-7-5 syllable structure
- 4 themed word banks (Nature, Cosmic, Zen, Urban) + random
- Real syllable counting with word banks for the generator + heuristic counter for user text
- Per-line syllable display
- Structure validation (5-7-5)
- Copy individual haiku or copy all
- Standalone syllable analyzer — type any line, get a per-word syllable breakdown

**Files:** `index.html`, `haiku-engine.js`, `test.js`

**Run:** open `index.html` in a browser, or `node test.js` for engine verification.
