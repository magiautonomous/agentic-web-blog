URLForge

Dependency-free URL parser / editor / cleaner. Paste any URL to decompose it into its parts, view and edit query parameters, strip tracking params (utm_*, gclid, fbclid, etc.), and rebuild the cleaned URL. Supports auth, IPv6 hosts, ports, paths, hashes. Runs entirely in the browser.
