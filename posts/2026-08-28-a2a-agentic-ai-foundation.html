A2A Gets a Neutral Home: Agent Interoperability Goes Foundation-Owned

2026-08-28

The agent layer of the web just got a governance answer. On 27 August 2026, the Agent2Agent (A2A) protocol was accepted as a Growth Stage project at the Agentic AI Foundation (AAIF) — the Linux Foundation-directed body that already stewards MCP, goose, and AGENTS.md. It reads like an administrative footnote, but it settles one of the open questions of the agentic web: who owns the standard that lets agents talk to each other? The answer is now: no single vendor.

Why A2A is the horizontal half of the stack

The division of labour that has stuck in 2026 is clean. MCP is the vertical layer — an application connecting to tools, data, and workflows over an open client-server protocol. A2A is the horizontal layer — one agent discovering, delegating to, and receiving results from another, regardless of which framework or company built it. Before A2A, hand-off between agents built on different frameworks meant writing bespoke integration code for every new pairing; the protocol turns that into a standardized client-server handshake with an Agent Card advertising capabilities.

A2A reached version 1.0 in 2026, and the consolidation is real: IBM's parallel Agent Communication Protocol (ACP) joined forces with A2A under the open-source umbrella back in August 2025, so teams now have one standard to plan against. On the adoption side, the ecosystem spans frameworks like LangGraph, CrewAI, Pydantic AI, and AG2, and enterprise platforms including ServiceNow, Salesforce, Atlassian, and SAP are connecting workflows across products with it.

Why neutral governance is the real news

Foundational infrastructure evolves openly, or it doesn't get adopted. By operating under AAIF alongside its sibling projects, A2A is protected from single-vendor constraints — the community shapes the roadmap, which is exactly the kind of predictability engineering teams need before betting an agent platform on it. The straightforward test for the agentic web in 2026: a project's governance is as important as its protocol. Tool access (MCP) and agent collaboration (A2A) are now both neutral, foundation-owned, and explicitly designed to work together — the web's agent layer is quietly getting its HTTP and TCP equivalents.

If you want to see the shape of it, the A2A getting-started guide walks through a first client-server pair in a few hundred lines. The interesting part is what that plumbing enables: agents that assume other agents exist, advertise what they can do, and hand work to each other without a human in the loop.
